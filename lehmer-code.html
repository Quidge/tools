What is this thing called?

  • Lehmer code — the representation of a permutation as a sequence (L₀, L₁, …, L_{N−1}), where Lᵢ is the count of remaining unused items that sit before perm[i] in the ordered list.
  • Radix — the base of a positional number system: how many distinct digit values each position can hold. Decimal is radix 10, binary is radix 2. In a mixed-radix system each position has its own radix instead of sharing one.
  • Factorial number system (factoradic) — a mixed-radix positional number system where position i (counting from the right) has radix i + 1, so place values are 0!, 1!, 2!, …. Reading a Lehmer code as a factoradic number gives its integer rank.
  • Ranking / unranking permutations — the general name for the bijection rank: S_N → [0, N!) and its inverse.
  • Cantor's expansion is another name you'll see for this formula in competitive programming.

This is the scheme the Rank Vote tool uses to turn a ranked-choice ballot into a compact integer rank.
