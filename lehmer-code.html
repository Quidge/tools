What is this thing called?

  • Lehmer code — the representation of a permutation as a sequence (L₀, L₁, …, L_{N−1}), where Lᵢ is the count of remaining unused items that sit before perm[i] in the ordered list.
  • Factorial number system (factoradic) — a mixed-radix positional number system with place values (N−1)!, (N−2)!, …, 1!, 0!. Reading a Lehmer code as a factoradic number gives its integer rank.
  • Ranking / unranking permutations — the general name for the bijection rank: S_N → [0, N!) and its inverse.
  • Cantor's expansion is another name you'll see for this formula in competitive programming.

This is the scheme the Rank Vote tool uses to turn a ranked-choice ballot into a short shareable code.
